# Horizon Chase universal port 1.0.0

First public BYO-data release of the native AArch64 Unity/IL2CPP compatibility
loader for Horizon Chase Android 2.6.9.

## Highlights

- one identical loader for NextOS Mali-450/fbdev, ArkOS/R36S Mali-G31/KMSDRM
  and NextOS Mali-G310/KMSDRM;
- complete races, original music and sound effects, native Xbox-style
  controls, persistent saves and clean frontend return;
- automatic EGL-context ownership, GLES/textures, audio backend and memory
  tier selection;
- native ASTC/ETC paths where supported and targeted software fallback for
  Mali-450;
- 30 Hz native lifecycle pacing and low-memory texture/allocator policy;
- transactional first-run setup with NXExtract 1.1.1;
- deterministic PortMaster package with an internal SHA-256 manifest.

## Install

1. Extract `horizonchase.zip` into the firmware's ports directory.
2. Put a legally owned ARM64 Horizon Chase Android 2.6.9 APK, all split APKs,
   or one complete APKS/APKM/XAPK bundle in `horizonchase/gamedata/`.
3. Launch **Horizon Chase**. The external filename does not matter.

No APK, Unity/IL2CPP library, art, music or other proprietary game payload is
included.

# Horizon Chase universal port 1.1.0-beta.1

Test release. Brings an owner's own Android profile into the port, so the
campaign they already paid for is available offline.

The loader binary is unchanged from 1.0.4
(`87f8c8a92979eb91f1d516318b70e8ce909c01f0038b53ce3e91893ba2bfc8c4`). Nothing
in the game's runtime behaviour was touched — this release only adds a setup
step that runs before the game starts.

## Why this exists

Horizon Chase is free-to-play. The APK ships every track, but everything past
the demo is released by an entitlement stored in the player's profile rather
than by the files on disk. That entitlement is granted by the Google Play
purchase flow, which an offline port has no bridge to. Until now a fresh
install therefore started on the demo even for someone who owned the game.

## What changed

- Drop `com.aquiris.horizonchase.v2.playerprefs.xml` into `gamedata/`, next to
  the APK. The next launch imports it on its own — no PC, no extra steps.
- The launcher validates the file is a real Horizon Chase profile, reports what
  it carries (revision, cups, races, tokens, entitlements), merges it into
  `userdata/shared_prefs.bin` and moves the source to `userdata/save-imports/`.
- The source is consumed once on purpose. Re-importing every launch would
  overwrite progress made on the handheld with the older phone profile.
- Only the profile is imported. The rest of a phone's SharedPreferences
  describes that phone — resolution, quality, audio routing — and would
  override the settings tuned for the handheld.
- A failed or skipped import never blocks the game from starting.

## Nothing is invented

The port releases only what the player's own profile already proves. There is
no bypass and no synthesized entitlement: a profile without the purchase
imports its progress, stays on the demo, and says so.

## Install

1. Extract `horizonchase.zip` into the firmware's ports directory.
2. Put a legally owned ARM64 Horizon Chase Android 2.6.9 APK, all split APKs,
   or one complete APKS/APKM/XAPK bundle in `horizonchase/gamedata/`.
3. Optional, if you own the full game on Android: also copy your
   `com.aquiris.horizonchase.v2.playerprefs.xml` into `horizonchase/gamedata/`.
   It lives at `/data/data/com.aquiris.horizonchase/shared_prefs/` and pulling
   it needs root or a backup tool that can read app-private data.
4. Launch **Horizon Chase**.

## Testing wanted

- a full-game profile imports and the campaign is available offline;
- a demo profile imports its progress and stays on the demo;
- launching with no profile in `gamedata/` behaves exactly as 1.0.4 did;
- settings tuned on the handheld survive an import.
